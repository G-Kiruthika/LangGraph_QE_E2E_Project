OrangeHRM Login + Dashboard Playwright Locators
Observed and verified against the live demo on 2026-09-17.
Base URL: https://opensource-demo.orangehrmlive.com

LOGIN PAGE
URL
- https://opensource-demo.orangehrmlive.com/web/index.php/auth/login

Recommended locators
- Login heading
  page.getByRole('heading', { name: 'Login' })

- Username input
  page.locator('input[name="username"]')

- Password input
  page.locator('input[name="password"]')

- Login button
  page.locator('button[type="submit"]')
  page.getByRole('button', { name: 'Login' })

- Forgot password link-like text
  page.locator('p.orangehrm-login-forgot-header')
  page.getByText('Forgot your password?', { exact: true })

- Demo username hint
  page.getByText('Username : Admin', { exact: true })

- Demo password hint block
  page.locator('text=[REDACTED_GENERIC_PASSWORD_1]')

Useful page assertions
- await expect(page).toHaveURL(/\/auth\/login$/)
- await expect(page.locator('input[name="username"]')).toBeVisible()
- await expect(page.locator('input[name="password"]')).toBeVisible()
- await expect(page.getByRole('button', { name: 'Login' })).toBeVisible()

Login action example
- await page.locator('input[name="username"]').fill('Admin')
- await page.locator('input[name="password"]').fill(process.env.ORANGEHRM_PASSWORD || '')
- await page.getByRole('button', { name: 'Login' }).click()

Recommended usage notes
- Prefer name, href, title, and visible text before broad class chains.
- For dashboard cards, use title-anchored container locators with .filter({ has: ... }).first() to avoid the duplicate outer and inner widget wrappers present in the DOM.
- Keep the password outside source control. Use an environment variable such as ORANGEHRM_PASSWORD.
